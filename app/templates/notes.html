What this demo is - and is not.

Maker Swap is a second-hand marketplace demo for makers and hobbyists in Singapore. It currently provides a public, mobile-friendly catalogue and item detail flow without sign-in.

Seeded demo data

The 16 listings, prices, conditions, descriptions, images and pickup areas are seeded. Pickup areas are display text, not seller identities or live locations.

Deliberate boundaries

There are no accounts, payments, messaging, shipping, seller profiles or multi-vendor systems. Those are outside this assessment's core flow.

AI usage

Development uses Codex CLI through CognitioLabs' gateway with gpt-5.6-terra. Natural-language search uses text-embedding-3-small through the backend; catalogue Q&A is not yet available.

Known limitations

Catalogue content is illustrative, category artwork is reused, and semantic search ranks only this small fixed catalogue. The demo does not yet answer catalogue questions.
